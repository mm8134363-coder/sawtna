# صوتنا — نسخة PWA جاهزة للتثبيت

## ما الذي تمت إضافته؟
- Web App Manifest
- Service Worker
- زر تثبيت داخل الصفحة عند توفر التثبيت
- دعم تثبيت الموقع كتطبيق مستقل على Android/Chrome
- أيقونات 192 و512
- تشغيل الواجهة الأساسية حتى بدون إنترنت بعد أول زيارة (للملفات المضمنة)

## طريقة الرفع
ارفع محتويات هذا المجلد إلى جذر موقع GitHub Pages نفسه:
- index.html
- style.css
- app.js
- manifest.webmanifest
- service-worker.js
- icons/icon-192.png
- icons/icon-512.png

بعد النشر افتح الموقع من HTTPS في Chrome على الهاتف، ثم استخدم زر «تثبيت صوتنا على الهاتف» أو قائمة Chrome ⋮ ثم «تثبيت التطبيق».

## مهم للدردشة الصوتية الحقيقية
هذه الحزمة تجعل الموقع PWA قابلة للتثبيت، لكنها لا توفر وحدها صوتًا جماعيًا بين مستخدمين مختلفين. ذلك يحتاج خادم WebRTC/Signaling (مثل WebSocket أو خدمة صوتية). لا يمكن جعل الاتصال الصوتي الجماعي الحقيقي يعمل بالكامل دون اتصال بالشبكة.
